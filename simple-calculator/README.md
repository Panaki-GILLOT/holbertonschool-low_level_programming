# Simple Calculator

## 📌 Description

This project is a simple terminal-based calculator written in C.

It allows the user to perform basic arithmetic operations through a menu-driven interface. The program runs in a loop until the user chooses to quit.

---

## ⚙️ Compilation

To compile the program, use the following command:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator
